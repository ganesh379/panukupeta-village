## 🌍 About

Panukupeta (పానుకుపేట) is a vibrant village in **Seethanagaram Mandal**, **Parvathipuram Manyam District**, Andhra Pradesh, India.

- 👨‍👩‍👧‍👦 ~1,074 residents | 275 households
- 📚 62.1% literacy rate
- 🌾 Paddy (rice) farming heartland
- 📮 Pincode: 535546
- 📍 ~7 km north of Bobbili town

## 🎨 Design

Built with a **Duolingo-inspired** design system:
- **Colors:** Ecto Green `#58cc02`, Lingot Lime `#a5ed6e`, Macaw Blue `#1cb0f6`
- **Typography:** Nunito (rounded, friendly)
- **Style:** Flat cartoon illustrations, thick border accents, no drop shadows
- **Animations:** Scroll reveal, floating hero image, number counters

## 🛠️ Tech Stack

- Pure **HTML5** + **Vanilla CSS** + **Vanilla JavaScript**
- No frameworks, no build tools — just open `index.html` in any browser!
- Google Fonts (Nunito)
- Responsive design (mobile-first)
